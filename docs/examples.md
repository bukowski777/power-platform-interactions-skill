# Examples

## Solution Review

```text
Use $power-platform-interactions to review this Dataverse solution export before I import it in DEV.
Check environment orientation, connection references, environment variables, deployment settings, workflow risks, and verification evidence.
Do not run import or publish.
```

## SQL Gateway Sync Design

```text
Use $power-platform-interactions to design a Power Automate sync from SQL Server via gateway to Dataverse.
Include SQL object contracts, stored procedure rules, batch size, watermark, idempotency, TRY/CATCH, and smoke tests.
```

## Copilot Studio Change

```text
Use $power-platform-interactions to inspect this Copilot Studio workspace change.
Find local/remote source-of-truth risk, connector action inputs, topic variables, validation commands, and test prompts before Apply Changes.
```

## SharePoint OCR Flow

```text
Use $power-platform-interactions to harden a SharePoint document ingestion flow with AI Builder OCR.
Focus on inline attachment filtering, duplicate keys, OCR normalization, metadata writes, and operator-visible errors.
```

## Client Handoff

```text
Use $power-platform-interactions to produce a client-ready handoff for this Power Platform delivery.
Use placeholders for tenant values and separate validation actually run from owner next actions.
```
