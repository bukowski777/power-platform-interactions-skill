# Use Cases

## Power Platform Consultants

Use this skill before tenant changes, solution imports, flow activation, app sharing, DLP changes, or production-sensitive connector work.

## Makers Working with Developers

Use it to bridge portal-created components and Git-reviewed artifacts: fresh exports, unpacked solution inspection, deployment settings, connection references, and handoff notes.

## Automation Builders

Use it to design or audit cloud flows that depend on SQL gateway, SharePoint, Dataverse, HTTP APIs, Outlook, Teams, AI Builder, or custom connectors.

## Copilot Studio Builders

Use it to keep local workspace changes synchronized with the remote agent, validate `.mcs.yml`, and avoid generative action calls with empty or stale pivots.

## Client Delivery Teams

Use it to produce evidence-backed delivery reports, incident notes, integration requests, and runbooks without leaking tenant data.

## Incident or Stabilization Work

Use it to separate symptoms, evidence, source of truth, tenant impact, rollback, and owner actions before changing a live component.
