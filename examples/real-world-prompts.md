# Real-World Prompts

## Reproduce a Solution on Another Tenant

```text
Use $power-platform-interactions to prepare a tenant reproduction plan for this Power Platform solution.
Use delegated user auth unless the project explicitly requires CI/CD.
List required environment variables, connection references, gateway permissions, import order, first-run checks, and owner actions.
Do not include secrets.
```

## Review an AI Builder OCR Flow

```text
Use $power-platform-interactions to review this AI Builder OCR flow.
Find risks around inline images, OCR amount parsing, date parsing, duplicate detection, metadata writes, raw payload logging, and error notifications.
```

## Validate a SQL Gateway Contract

```text
Use $power-platform-interactions to validate this SQL gateway contract for Power Automate.
Check explicit schema, SELECT/EXECUTE grants, SET NOCOUNT ON, one result set, stable columns, batch limits, and metadata cache risks.
```

## Prepare a Copilot Studio Apply Changes

```text
Use $power-platform-interactions to prepare this Copilot Studio Apply Changes.
Check Preview/Get Changes, local schema validation, connector action inputs, connection references, stale variables, and test prompts.
```

## Client Delivery Note

```text
Use $power-platform-interactions to write a delivery note from these validation results.
Use the handoff template, keep it client-ready, and separate completed checks from remaining owner actions.
```
